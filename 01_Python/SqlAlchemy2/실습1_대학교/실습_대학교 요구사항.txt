`학과` 는 고유한 id 값과 학과이름 속성을 갖는다
`학생` 은 고유한 id 값과 학생이름과 학년 속성을 갖는다. 학년은 1~4 사이의 정수
`교수` 는 고유한 id 값과 교수이름 속성을 갖는다
`과목` 은 고유한 id 값과 과목이름과 학점 속성을 갖는다. 학점은 1~5 사이의 정수

`학생` 은 하나의 `학과`에 반드시 소속된다.
`교수` 는 하나의 `학과`에 반드시 소속된다.
`교수` 는 여러 `과목` 을 강의할수 있다.
한명의 `학생` 은 여러개의 `과목` 을 수강할수 있고,  하나의 `과목` 은 여러 `학생`이 수강할수 있다.

[필요한 동작들]
- 특정 `학생` 이 수강하는 `과목`들 목록 조회
- 특정 `학과` 에 소속된 `교수` 들 목록 조회
- 특정 `교수` 의 `학과` 정보 조회
- 특정 `학생` 의 `학과` 정보 조회
- 특정 `과목` 을 수강하는 `학생` 목록 조회 
- `과목` 별 수강하는 `학생` 의 수 조회.
- 특정 학년의 `학생` 들이 소속된 `학과`
